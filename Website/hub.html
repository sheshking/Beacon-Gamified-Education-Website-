🏆 BEACON ARCADE MANIFESTO: Empowering code mastery through gamified retro terminal exploration.
⚔️ How do I earn XP, level up, and unlock arcade badges? ▼ EXPAND
You earn XP by completing quest lessons (+10 XP each, once per lesson), watching Video Theater lessons and marking them complete (+50 to +150 XP depending on the video), and transmitting feedback through this Hub (+25 XP every time). Badges and levels are shown on your Profile page — right now badge unlocking is still a placeholder, so the badge slots you see there are a preview of what's coming rather than fully wired up yet.
⚡ How does the Real Execution Terminal verify my code? ▼ EXPAND
For Python, your code runs for real in your browser through Pyodide, an actual Python interpreter — the output you see is genuine. For Java and C++, there's no full compiler running in the browser, so a lightweight custom Beacon interpreter checks the print statements, variables, and math your code produces against the expected output. It covers everything taught in the current lessons, but it isn't a real Java or C++ compiler.
🎬 Can I practice coding while watching the video lessons? ▼ EXPAND
Not yet — the Video Theater and the coding Quest terminal are currently separate experiences. Watch a video, then head to the matching language quest to practice what you learned in the terminal. A combined watch-and-code view may come later.
🏆 How do consecutive streaks and login bonuses work? ▼ EXPAND
Honestly, right now the streak counter shown in the HUD bar is a placeholder and doesn't yet track real day-to-day logins automatically. Daily streak tracking and login bonuses are planned but not live in this build yet.
⚙️ What programming languages and tiers are currently supported? ▼ EXPAND
Beacon currently supports Python, Java, and C++, each with a "Basics & Input/O" lesson section covering ten levels from Hello World through combined variable output. Difficulty tiers are Beginner, Intermediate, and Expert, chosen when you sign up.
